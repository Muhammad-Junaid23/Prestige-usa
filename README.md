Getting Started / Setup

To run or develop locally:

Clone the repository

git clone https://github.com/your-org/prestigeusa-website.git
cd prestigeusa-website


Install dependencies (if using build tools, bundlers, package managers)

npm install  
# or yarn install  


Start development server

npm run dev  
# or equivalent (e.g. `npm start`, `gatsby develop`, `hugo server`, etc.)


Build for production

npm run build  


Preview production build

npm run serve  


Note: If the site is purely static (HTML/CSS/JS), these commands may not apply — omit unnecessary steps.
